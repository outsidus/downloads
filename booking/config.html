—

1) 저장소 연결

GitHub Contents API 로 직접 불러오고 저장합니다. 토큰은 이 브라우저에만(localStorage) 저장되고 github.com 으로만 전송됩니다.

2) 이 기기별 부킹 on/off devices

앱 설정 화면의 이름 또는 UUID 를 넣고 스위치로 제어. 목록에 없는 기기는 기본 허용.

3) 예약 안 할 날짜(여행 등) skipDates

해당 날짜는 휴관 처리되어 자동으로 건너뜁니다.

4) 운영 타입 오버라이드 dayTypeOverrides

특정 날짜의 운영 타입을 지정. (0 평일 · 1 휴일 · 2 휴관 · 3 특별휴일)

5) 운영 시작 시각 startHour

비워두면 앱 기본값 사용(서버가 건드리지 않음).

6) 요일/특정일 우선순위 priorityOverrides

좌석/시간은 쉼표 구분. 비운 칸은 상속. 우선순위: 날짜 > 요일 > 기본.
